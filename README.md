# 📌 Мой основной проект

<div align="center">

## 📊 Анализ реестра предпринимателей

</div>

Проект посвящён анализу данных из **реестра предпринимателей**.  
В рамках работы я исследовал структуру данных, выполнял их обработку и анализировал закономерности, которые можно использовать для лучшего понимания набора данных.

### В проекте я работал над следующим:
- очистка и подготовка данных;
- исследовательский анализ данных (EDA);
- поиск закономерностей и интересных наблюдений;
- визуализация результатов;
- формулировка выводов по итогам анализа.

### Что показывает этот проект:
- умение работать с реальными данными;
- навык структурирования аналитической задачи;
- применение Python и библиотек для анализа данных;
- умение интерпретировать результаты исследования.
